# flower-gpu

A Three.js WebGPU phyllotaxis flower. Petal counts, placement, colors, and the control panel follow the public study at `https://moaaz-rafique.vercel.app/phyllotaxis/`, read with [REA](https://github.com/morluto/rea) 6.8.0. The page is our own TSL material, mesh, and lil-gui panel.

```bash
bun install
bun run dev
```

Drag to orbit. Scroll to dolly. Space plays the bloom. Left and right arrows change the flower.
